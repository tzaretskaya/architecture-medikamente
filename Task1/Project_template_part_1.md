### 1. Проблемные зоны

- конфиденциальные данные клиентов хранятся в excel или сканах и лежат на общем диске
- Работа с данными производятся сотрудниками без разграничений прав
- хранение и обработка данных небезопасна: отсутствует шифрование
- отсутствует утилизация данных
- отсутствует контроль своих данных пользователями

### 2. Что можно улучшить

- Медицинские карты (история болезней, диагнозы, назначения, результаты осмотров), паспортные данные, СНИЛС, полисы ОМС/ДМС, ФИО, дата рождения, адрес, телефон, email -- все должно быть зашифровано в основной бд, при использовании аналитиками должно маскироваться 
- Фотографии, сканы документов (JPG, PDF) -- Все файлы в хранилище должны быть зашифрованы
- Банковские реквизиты пациентов и компании, данные кредитных карт -- шифрование при хранении и передаче
- Данные из 1С: Бухгалтерия (зарплаты, платежи, финансовые отчёты) -- шифрование. Для аналитики обезличивание
- Данные из 1С: Торговля и склад (стоимость ТМЦ, закупочные цены) -- шифрование
- Логины, пароли -- захешированы
- Токены доступа -- шифрование
- Журналы аудита (кто, когда, что сделал) -- для мониторинга и логов обезличивание
- Персональные данные в логах должны быть зашифрованы


Тегирование с примерами полей:
- уровень конфиденциальности:\
  CRITICAL: diagnosis, medical_history, passport_data, genetic_data,\
  HIGH: full_name, phone, email, address, insurance_data,\
  MEDIUM: age_group, general_stats, department_analytics,\
  LOW: anonymized_stats, public_health_data
- категория: \
 PII: full_name, passport, phone, address,\
 PHI: diagnosis, treatment_plan, medical_history, test_results,\
 FINANCIAL: insurance, payment_info, pricing,\
 CLINICAL: lab_results, imaging_studies, prescriptions,\
 OPERATIONAL: appointments, staff_schedules, inventory\
- время хранения: \
 PERMANENT: medical_diagnosis, surgical_history,\
 10_YEARS: medical_records, test_results,\
 5_YEARS: financial_records, insurance_data,\
 3_YEARS: appointment_logs, operational_data,\
 1_YEAR: temp_files, cache_data


В качестве системы тегирования можно воспользоваться инструментом Collibra:
она автоматически обнаруживает, классифицирует и визуализирует данные. Есть интегарции с Excel, PostgreSQL. Возможно сынтегрироваться с 1C.
Встроены шаблоны для 152-ФЗ. Имеется отличная поддержка медицинских данных.

Инструменты для обеспечения конфиденциальности в потоках:
- шифрование трафика TLS
- Запись в защищенный журнал аудита
- DLP-сканирование на наличие избыточных персональных данных
- двухфакторная аутентификация сотрудника
- Шифрование медицинских файлов
- RBAC: ролевая модель + врачи видят только своих пациентов
- PCI DSS compliance для обработки платежей
- Токенизация платежных данных
- Аудит всех финансовых операций
- Резервное копирование в георазнесенные дата-центры
- JWT tokens для API
- ELK Stack для логов
- Ежеквартальные аудиты доступов
- Отчеты о нарушениях политик
- автоматическое тегирование
